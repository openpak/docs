# PlayStation 4

OpenPak has started work on the PlayStation 4, but there is **nothing for players to set up
yet**.

!!! warning "Very early"
    No real PS4 has been tested with OpenPak, and there is no PS4 patcher.

## What exists

- A server for the console's **system update list**, which tells a PS4 that its firmware is
  already current. It is running. It is the only PS4 service so far.

## What does not exist yet

- PlayStation Network sign-in, friends, trophies and online games. The PS3 services do not
  cover the PS4, and PS4 sign-in is a separate piece of work that has not started.
- A DNS setting or patcher to point a PS4 at OpenPak. Do not change your PS4's network
  settings for OpenPak yet.
- A PS4 emulator.

This page will get real steps when a PS4 has been verified. Progress is on
[openpak.org/features](https://openpak.org/features).
