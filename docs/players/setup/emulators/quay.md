# Quay (Wii U)

Quay will be OpenPak's Wii U emulator, booting the console's own Wii U Menu and applets.

## Status

**Not ready yet.** The code is still a copy of the retired OpenPak Cemu fork, has not been run as
Quay, and has no tested build.

## Downloads

- **Release:** [github.com/openpak/quay/releases/latest](https://github.com/openpak/quay/releases/latest),
  once a tagged release exists.
- **Nightly:** the rolling [`nightly` pre-release](https://github.com/openpak/quay/releases/tag/nightly),
  rebuilt when the source changes. It is untested: use it to follow progress, not to play.

## Sign in to OpenPak

Quay has no OpenPak sign-in yet. On a real Wii U, see the [Wii U guide](../wiiu.md).

## Known limits

- Nothing has been tested against a game or against OpenPak.
- The program and its files are still named Cemu until the rename lands.

Issues: [github.com/openpak/quay/issues](https://github.com/openpak/quay/issues). Say which
build you used (release or nightly) and what you saw.
