# Berth (Xbox)

Berth is OpenPak's original Xbox emulator, built on xemu. It boots a dashboard you supply.

## Status

**Not ready yet.** No OpenPak service has been reached from it yet.

## Downloads

- **Release:** [github.com/openpak/berth/releases/latest](https://github.com/openpak/berth/releases/latest),
  once a tagged release exists.
- **Nightly:** the rolling [`nightly` pre-release](https://github.com/openpak/berth/releases/tag/nightly),
  rebuilt when the source changes. It is untested: use it to follow progress, not to play.

## Sign in to OpenPak

There is no way to sign in to OpenPak from Berth yet.

## Known limits

- No OpenPak connection at all yet.
- You supply the BIOS, dashboard and games from your own Xbox.

Issues: [github.com/openpak/berth/issues](https://github.com/openpak/berth/issues). Say which
build you used (release or nightly) and what you saw.
