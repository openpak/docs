# Berth (Xbox)

Berth is OpenPak's original Xbox emulator, built on xemu. It boots a dashboard you supply.

## Status

**Experimental. Dashboard sign-in works.** In October 2026 Berth, running an Xbox dashboard you
supply, signed in to OpenPak's Xbox services: the friends list, account sign-up and
dashboard voice-chat sessions were used from the dashboard. Not verified: any game online, and
a real original Xbox.

## Downloads

There is no download yet. No tagged release exists, and the rolling
[`nightly` pre-release](https://github.com/openpak/berth/releases/tag/nightly) has no files
(its last build failed). Berth can be built from source from
[github.com/openpak/berth](https://github.com/openpak/berth).

## Sign in to OpenPak

Use the dashboard's own sign-in with your OpenPak account.

## Known limits

- No game has been played online.
- You supply the BIOS, dashboard and games from your own Xbox.

Issues: [github.com/openpak/berth/issues](https://github.com/openpak/berth/issues). Say which
build you used (release or nightly) and what you saw.
