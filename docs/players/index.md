# What OpenPak is

OpenPak is a community-run online network for game consoles whose official online services
have closed or are closing. Your console (or an OpenPak emulator) is pointed at OpenPak instead
of the vendor's servers. The console keeps running its own firmware and your own games; only
the servers on the other end are replaced.

With one OpenPak account you get:

- **One account for every console.** Register once on [openpak.org](https://openpak.org), then
  link consoles and emulators to it. Every linked device is listed and can be revoked.
- **Friends that follow you.** Share a friend code, send and accept requests, chat and block.
  The friend list is one list across every OpenPak platform.
- **Online play** in the games OpenPak has a server for.
- **Cloud saves** for supported consoles and emulators.
- **A companion app** for your account, friends, invitations and saves on your phone.

OpenPak's servers are free software (AGPL-3.0). Nothing depends on a vendor staying online.

[openpak.org/features](https://openpak.org/features) and always wins over this page.

| Platform | State | Notes |
| --- | --- | --- |

| 3DS | Beta | As for the Wii U. The console patch (nimbus) is alpha. |

| DS | Beta | Nintendo Wi-Fi Connection. |
| Xbox (original) | In development | Not ready for players yet. |
| Xbox 360 | In development | Not ready for players yet. |
| PlayStation 3 | In development | Not ready for players yet. |
| PSP, PS2, PS Vita, PS4, PS5, Xbox One | Planned | Nothing to set up yet. |

## Which games work

Every game OpenPak knows about is on [openpak.org/titles](https://openpak.org/titles), with
its state and what was tested. The words mean:

| State | Meaning |
| --- | --- |
| **Live** | Served and played online on real hardware. |
| **Beta** | Served and running, but not yet verified on a console. |
| **Alpha** | Being brought up. Expect it not to work. |
| **Requestable** | No server yet. You can ask for it on the titles page. |

Switch has the most live games so far, among them Mario Kart 8 Deluxe, Splatoon 2 and 3,
Animal Crossing: New Horizons, Stardew Valley, Terraria, Don't Starve Together and the Risk of
Rain games. Check the titles page for the current list before you set anything up for one game.

## Alpha caveats

- **Data may be reset.** Accounts, friend lists, console links and cloud saves can be reset or
  lost while the network is built. The site will say so before a planned reset.
- **No uptime promise.** Services can be down without notice. Check
  [status.openpak.org](https://status.openpak.org).
- **Partial features are partial.** A game that starts online is not proof that every mode
  works. Game invitations are delivered, but joining a game from one does not always work yet.
- **Bans by the vendor are possible.** Read [before you start](before-you-start.md).
- **You must be at least 16** to create an account.
