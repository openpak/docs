# FAQ

## Is OpenPak free?

Yes. There is no charge for the account or the network, and the servers are free software.

## Is it finished?

No. OpenPak is in public alpha. The Switch works best; Wii U, 3DS, Wii and DS are in beta;
Xbox, Xbox 360 and PS3 are in development. See [what works today](index.md#what-works-today).

## Can I get banned?

By OpenPak, only for breaking the [Terms](https://openpak.org/terms). By the console's
vendor, **yes**, if a modified console reaches the vendor's servers. Read
[before you start](before-you-start.md).

## Do I need a Nintendo Switch Online membership?

Not from Nintendo. OpenPak answers the membership check itself, so games that need a
membership see one.

## Can I play with people on the official networks?

No. OpenPak is a separate network. You play with other people on OpenPak.

## Do my friends from the official network carry over?

No. Add your friends again with their OpenPak friend codes. On OpenPak your friend list is
shared across every console you link.

## Can a friend on another console see me?

Yes. There is one friend list for every OpenPak platform, and presence is shared across them.

## Can I use OpenPak and the official network on the same Switch?

Not on the same system at the same time. Use an emuMMC for OpenPak, and always select
**Nintendo** in OpenPak Setup, then reboot, before that system talks to Nintendo again.

## Does OpenPak modify my games?

On Switch, Wii U and 3DS, OpenPak changes where the console connects, not the games. The one
exception is a small data-only patch for Crash Team Racing Nitro-Fueled on the Switch (see
[what it changes](setup/switch.md#what-it-changes)). Wii and DS games have no other way in, so
their patchers redirect each game.

## Where do I get games, keys or firmware?

Not from OpenPak. Use your own console and your own games. OpenPak never provides copyrighted
files and these docs do not explain how to get them.

## My game is not listed, or says "Requestable".

There is no server for it yet. Request it on [openpak.org/titles](https://openpak.org/titles)
or in the app.

## Why does a game need its latest update?

OpenPak serves the current version of each game only, and refuses older versions with
error 2124-3001.

## Can I run my own OpenPak?

Yes. The code is AGPL-3.0. See [self-hosting](../self-hosting/index.md). You can also help the
main network by running an [approved federation node](../self-hosting/become-a-node.md).

## Is OpenPak affiliated with Nintendo, Microsoft or Sony?

No. OpenPak is an independent community project.
